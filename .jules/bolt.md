## 2024-05-24 - Optimize SPI Transfers with Block Writes and Memory Safety
**Learning:** In Arduino LoRa drivers (sx126x/sx128x), replacing byte-by-byte `SPI.transfer` loops with block transfers `SPI.transfer(buffer, size)` significantly improves throughput. However, `SPI.transfer(buffer, size)` mutates the input buffer. When reading from a `const` buffer, you must prevent overwriting read-only memory by chunking data into a temporary stack buffer (e.g., `uint8_t temp[32]`) and transferring chunks. This avoids memory corruption while maintaining a small stack footprint safely.
**Action:** Always verify if an optimized function mutates input arguments. If `const` is required, use stack-allocated chunking to bridge the gap between safety and performance in embedded systems.
